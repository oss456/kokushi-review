国試リビュー v2

【追加した機能】
・Photo：iPhoneのカメラ／写真ライブラリから画像をカードに添付して保存・復習できます。
・Schedule：復習結果に応じて次回復習日を1/3/7/14/30/60日程度の間隔で調整します。もう一度＝翌日、難しい＝短め、覚えた＝段階的に延長。
・Wrong：『もう一度』を選んだカードを苦手一覧に登録し、苦手カードだけを復習できます。『覚えた』で苦手解除。
・Stats：累計回答数、正答率、定着カード数、科目別の回答状況を表示します。
・旧版のカードデータを引き継ぐ設計です。設定から旧版バックアップJSONも読み込めます。

【重要な制限】
写真をカードに添付する機能はありますが、写真の内容をAIが自動で読み取り、問題・解説を生成する機能は含みません。AI自動生成にはサーバー側のAI API接続とAPIキー管理が必要です。APIキーをブラウザ内に直接埋め込む設計は安全でないため、この静的版には実装していません。

【公開方法（GitHub Pages）】
1. ZIPを解凍し、index.html / manifest.webmanifest / sw.js をリポジトリの一番上にアップロード
2. GitHubのSettings → Pages → Deploy from a branch → main → /(root) → Save
3. 公開URLをiPhoneのSafariで開き、共有 → ホーム画面に追加

【データについて】
カード・写真・復習履歴は利用中のブラウザ内（localStorage）に保存されます。別端末との自動同期はありません。SafariのWebサイトデータ消去で消える場合があるため、設定から定期的にバックアップしてください。写真を多く登録すると容量を使います。
